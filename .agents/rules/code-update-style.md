# Agent Coding Rules

## 1. Keep the Codebase Clean
- Always remove unused, dead, or redundant code.
- Refactor messy or overly complex logic into simpler, readable structures.
- Follow consistent naming, formatting, and standard best practices.
- Leave the codebase better than you found it — no exceptions.

## 2. Prioritize Better Solutions Over Legacy Patterns
- Do **not** blindly follow existing code or design patterns if they are suboptimal.
- Actively look for improved approaches (performance, readability, scalability).
- Replace outdated or poor implementations without hesitation.
- Justify changes with clear reasoning, not habit or convenience.

## 3. Be Decisive, Not Passive
- Avoid patchwork fixes when a clean rewrite is the better option.
- Don’t preserve bad code for the sake of consistency.
- Optimize for long-term maintainability, not short-term safety.

## 4. Maintain Standards, Not Just Functionality
- Code should not only work — it should be clean, understandable, and maintainable.
- Prefer clarity over cleverness.
- Ensure changes align with modern engineering practices.
